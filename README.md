# RU Study Planner

แอปช่วยเรียนภาษาไทย: ติวก่อนเรียน พื้นที่เนื้อหาจากห้องเรียน สมุดจด แบบฝึกทบทวน แผนการเรียน และปฏิทิน

## การทำงาน

- เปิดบทเรียนและปฏิทินทันที ไม่มีหน้าล็อกอินหรือขั้นตอนสมัครสมาชิก
- เก็บโน้ต ความคืบหน้า คำตอบ และการปรับแผนใน Supabase ตามลิงก์พื้นที่ส่วนตัว
- สมุดจดรองรับหัวข้อ รายการ ตัวหนา สีตัวอักษร ไฮไลต์ รูปภาพ ค้นหา แท็ก และคำถามทบทวน
- อัปโหลดรูปเข้า private Storage ก่อนแทรกลงโน้ต รองรับ JPG/PNG/WebP/GIF ไม่เกิน 5 MB ต่อรูป
- แสดงสถานะบันทึกออนไลน์ทุกหน้า และยืนยันว่าบันทึกสำเร็จเมื่อฐานข้อมูลตอบกลับแล้ว
- เปิดจากเครื่องอื่นด้วยลิงก์ส่วนตัวเดียวกันเพื่ออ่านข้อมูลชุดเดียวกัน
- ถ้าเน็ตหลุด เก็บคิวชั่วคราวและลองส่งใหม่เมื่อเชื่อมต่อได้ ตรวจ revision เพื่อป้องกันการเขียนทับจากอีกเครื่อง
- ส่งออกและนำเข้าไฟล์สำรองโน้ตพร้อมรูป รวมถึงพิมพ์โน้ตเป็น PDF ผ่านเบราว์เซอร์
- แยกปฏิทินบรรยายกับสอบ มีตัวกรองและลิงก์แหล่งอ้างอิง
- แผนอ่านเริ่ม 1 พ.ย. 2569 ค่าเริ่มต้นวันละ 2 ชั่วโมงทั้งวันธรรมดาและวันหยุด: ทวน 15 / อ่าน 50 / ทำข้อสอบ 30 / วิเคราะห์เฉลย 20 / จด 5 นาที เลือกวันที่ดูแผนล่วงหน้าได้ และเก็บชั่วโมงที่ปรับแยกแต่ละวัน
- ฝึกจากคำถามเดิมรวม 505 ข้อ เฉลยหลังตอบ ข้อผิดวนกลับทันที และข้อที่ตอบถูกนัดทวน 1, 3, 7, 14 วัน บันทึกสถิติและวันนัดในพื้นที่ Supabase เดิม คำตอบเก่าที่ทำค้างไว้จะเข้าคิวทบทวนแยก โดยยังไม่นับเป็นครั้งฝึกหรือคะแนนจนกว่าจะตอบใหม่
- เมนูเอกสารมหาวิทยาลัยเปิด PDF ในแอปหรือไฟล์เต็ม พร้อมลิงก์ต้นฉบับที่ยืนยันได้: หลักสูตร 2569, ม.ร.30 ภาค 2/2569, หน้าที่เกี่ยวข้อง และระเบียบการสมัครที่เคยส่ง
- หน้าสอบแยกหลักฐานปรนัยย้อนหลังของทั้ง 7 วิชาจากสถานะ **ยังไม่ยืนยันรูปแบบเฉพาะภาค 2/2569** พร้อมภาคที่ตรวจและแหล่งข้อมูลรายวิชา

## หน้าตาและแรงจูงใจ

- หน้าหลักมีปุ่มเดียวที่ชัดที่สุดคือ “เริ่มภารกิจถัดไป” พาไปช่วงแรกของแผนรายวันที่ยังไม่ทำ (ข้ามการ์ดถ้ายังไม่มีการ์ดถึงรอบ) หรือบทที่อ่านค้างไว้
- “น้องสมุด” มาสคอตรูปหนังสือสวมหมวกบัณฑิต พูดให้กำลังใจตามสถานการณ์ของวัน และดีใจเมื่ออ่านจบหรือเลเวลอัป
- XP เลเวล 10 ขั้น และเหรียญ 12 เหรียญ คำนวณจากความคืบหน้าที่บันทึกอยู่แล้วเท่านั้น (`dist/gamify.js`) ไม่เพิ่มฟิลด์ใหม่ในข้อมูลส่วนตัว ทุกเครื่องจึงเห็นตัวเลขเดียวกัน
  - อ่านจบ 1 บท +50 · ตอบโจทย์ถูกครั้งแรก +10 (คำถามท้ายบท แนวข้อสอบ และฝึกสอบ) · ตอบถูกซ้ำตอนวนทบทวน +2 · ทบทวนการ์ดใบใหม่ +5 · ทำภารกิจในแผนรายวัน 1 ช่วง +10
  - XP จากโจทย์นับจากประวัติการฝึก (`practiceReview`) จึงไม่ลดเมื่อกด “ลองใหม่” หรือล้างคำตอบแนวข้อสอบ ส่วนการยกเลิกเครื่องหมายอ่านจบจะหัก XP ของบทนั้นคืน
- เอฟเฟกต์ฉลอง (คอนเฟตตี +XP ลอย การ์ดเลเวลอัป) อยู่นอก `#main` และปิดเองเมื่อเครื่องตั้งค่าลดการเคลื่อนไหว
- คำสำคัญท้ายบทเป็นการ์ดแตะเพื่อทายความหมายก่อนเปิดดู มีปุ่มเปิดดูทั้งหมด และแสดงครบเมื่อพิมพ์
- แฟลชการ์ดวางปุ่ม “ยังไม่แม่น / จำได้แล้ว” ไว้ในการ์ด ตอบได้โดยไม่ต้องเลื่อนหน้าบนมือถือ
- มือถือ: แถบล่างมี หน้าหลัก ติว ทบทวน สมุดจด และ “เมนู” ที่เปิดหน้าที่เหลือ (ฝึกสอบ แผน ปฏิทิน เอกสาร รางวัล ฯลฯ) ในแตะเดียว
- คงข้อกำหนดการอ่านเดิม: พื้นสว่างโทนน้ำเงิน ตัวอักษรหลักเข้ม หัวตารางน้ำเงินเข้ม ไม่ใช้ข้อความเทาอ่อน

## สมุดจดและลายมือ

- เมนูสมุดจดอยู่บนแถบหลักของมือถือ แยกประเภทบันทึกทั่วไป ติวก่อนเรียน และจดจากห้องเรียน
- ปุ่ม “เขียนด้วยปากกา” เปิดกระดาษ Canvas ใช้ Pointer Events รองรับปากกา เมาส์ และนิ้วเมื่อเปิดตัวเลือก
- เลือกสี ความหนา ยางลบ ย้อนกลับ และทำซ้ำได้ ปิดการเขียนด้วยนิ้วเป็นค่าเริ่มต้นเพื่อลดรอยจากฝ่ามือ
- กดบันทึกเพื่อสร้าง PNG และอัปโหลดเข้าที่เก็บรูปส่วนตัวของโน้ตบน Supabase ภาพที่บันทึกแล้วไม่ได้เก็บเส้นเป็นเวกเตอร์สำหรับแก้ต่อ
- แบบร่างลายมือยังไม่บันทึกออนไลน์จนกดบันทึก หากอัปโหลดไม่สำเร็จกระดาษยังเปิดไว้ให้ลองใหม่
- เนื้อหาจริงจากห้องเรียนยังรอผู้ใช้ส่งมา ไม่ใช้บทติวหรือความคืบหน้าติวแทน

## เนื้อหาติวก่อนเรียน

- **ภาค 1 พื้นฐาน** (บทที่ 1–5 ของทุกวิชา): บทเดิมจาก catalog พร้อม “เข้าใจใน 1 นาที” และส่วน **เจาะลึก** ต่อท้าย — เปิดเรื่อง ตารางเปรียบเทียบ ชื่อนักคิด/ปี/กฎหมายที่ตำรามักถาม แฟลชการ์ดและคำถามเพิ่ม
- **ภาค 2 เจาะเนื้อหาตามตำรา** (บทที่ 6 ขึ้นไป): บทเต็มตามโครงตำราแต่ละวิชา มีตัวอย่าง จุดที่มักสับสน และคำถามท้ายบท
- ทุกบทเจาะลึกมี **แหล่งอ้างอิงและอ่านต่อ** ท้ายบท ลิงก์ใส่เฉพาะที่ตรวจพบจริงจากผลค้นหา ไม่มีเลขหน้าที่ตรวจไม่ได้
- เนื้อหาเขียนใหม่ทั้งหมด ไม่คัดลอกตำราหรือข้อสอบ และ **ตรวจข้อเท็จจริงทีละบท** (ชื่อ ปี ตัวเลข มาตรา เฉลย) ก่อนเผยแพร่ เหตุการณ์ล่าสุดระบุ “ข้อมูล ณ ต.ค. 2569”
- ครบทั้ง 7 วิชา: 73 บท (ภาค 1 เจาะลึก 35 บท + ภาค 2 ใหม่ 38 บท) คำถามท้ายบท 332 ข้อ แฟลชการ์ด 810 ใบ แหล่งอ้างอิง 625 รายการ อ่านรวมประมาณ 38 ชั่วโมง

เนื้อหาเจาะลึกอยู่ใน `dist/deep/` (ไฟล์คงที่ แคชได้ ไม่เข้าฐานข้อมูล) ส่วน 35 บทพื้นฐานยังอ่านจาก catalog ตามเดิม `lessons.js` นำสองส่วนมารวมกัน โดยต่อท้ายการ์ดและคำถามเสมอ คำตอบและรอบทบทวนที่บันทึกไว้จึงไม่เลื่อนตำแหน่ง

แก้หรือเพิ่มเนื้อหาเจาะลึก:

```sh
node scripts/deep-parts.mjs split POL1101      # แยกเป็นไฟล์รายบทใน drafts/deep/POL1101/
node scripts/deep-parts.mjs check drafts/deep/POL1101/*.js
node scripts/deep-parts.mjs merge POL1101      # รวมกลับเป็น dist/deep/POL1101.{expand,lessons}.js
node scripts/validate-content.mjs POL1101
node scripts/build-deep-index.mjs <cache-version> POL1101,…   # ระบุวิชาที่ตรวจครบแล้วเท่านั้น
```

## เริ่มพัฒนา

Frontend เป็น static app ใน `dist/` ใช้ hash routing ใช้ Quill และ Supabase JS แบบตรึงรุ่นและเก็บ browser assets ใน repository

```sh
npm run check
npm test
python3 -m http.server 8080 --directory dist
```

`vercel.json` ระบุ build check และโฟลเดอร์ `dist/` สำหรับ deployment ส่วน GitHub Actions ตรวจ syntax และ tests ก่อนเผยแพร่

## พื้นที่ส่วนตัวโดยไม่ใช้หน้าล็อกอิน

แอปสร้างคีย์สุ่ม 256 บิตในเบราว์เซอร์ และส่งให้ Edge Function ผ่าน header ทุกครั้ง เซิร์ฟเวอร์เก็บเฉพาะ SHA-256 ของคีย์ ส่วนคีย์ต้นฉบับอยู่ในลิงก์ส่วนตัวและเบราว์เซอร์ของเจ้าของ ไม่มีคีย์ส่วนตัวใน source code

ใช้เมนู **ข้อมูลและเปิดบนอีกเครื่อง → คัดลอกลิงก์เปิดบนอีกเครื่อง** เพื่อเปิดข้อมูลชุดเดิมในอุปกรณ์ใหม่ ลิงก์มีสิทธิ์อ่านและแก้ไขข้อมูล จึงควรเก็บไว้ส่วนตัว คีย์อยู่หลัง `#space=` ไม่ส่งไปยังเซิร์ฟเวอร์โฮสต์หน้าเว็บ และถูกนำออกจากแถบที่อยู่หลังเบราว์เซอร์จำคีย์สำเร็จ

- Migration: `database/personal-link-workspaces.sql`
- Edge Function: `supabase/functions/personal-study/` — ปิด platform JWT check เพราะ handler ตรวจ private key เองก่อนทำรายการข้อมูลทุกครั้ง
- ตาราง `ru_study_personal_spaces` เปิด RLS และไม่ให้สิทธิ์ anon/authenticated อ่านเขียนโดยตรง ใช้ server role เฉพาะใน Edge Function
- รูปอยู่ใน private bucket `ru-study-personal-notes` แยกโฟลเดอร์ตามพื้นที่; ทุกการอัปโหลดและดาวน์โหลดตรวจคีย์
- ข้อมูลระบบ Auth เดิมยังคงอยู่ ไม่มีการย้ายหรือเปิดเผยข้อมูลบัญชีเดิมอัตโนมัติ
- แคชในเครื่องใช้พักงานเมื่อเน็ตขัดข้อง ข้อมูลหลักยังอยู่ใน Supabase; revision ป้องกันการเขียนทับจากอีกเครื่อง

เนื้อหาบทเรียนและลิงก์ต้นฉบับอ่านจาก catalog API แยกจาก workspace ส่วนตัว ตารางของภาคใหม่ต้องอัปเดตจากมหาวิทยาลัย ไม่คัดลอกวันสอบของภาคเก่าไปใช้

## การตรวจรุ่นนี้

ทดสอบการเปิดบทเรียนก่อนเชื่อมต่อพื้นที่ส่วนตัว การบันทึกโน้ตและรูปผ่าน private link การเปิดข้อมูลจากอุปกรณ์ที่ไม่มีแคช เครือข่ายขัดข้อง พื้นที่เครื่องเต็ม และ revision conflict รวมถึงการปฏิเสธคีย์ที่ไม่มีสิทธิ์

ชุดทดสอบหน้าจอเป็น render/event integration ไม่ใช่ browser E2E หรือการตรวจ layout บนมือถือจริง

รุ่นปรับหน้าตา (19 ต.ค. 2569) เพิ่มการทดสอบการคำนวณ XP เลเวล วันต่อเนื่องสูงสุด และเหรียญ รวมถึงหน้ารางวัลและเมนูมือถือ ส่วน layout ตรวจด้วยภาพหน้าจอ Chromium ที่ความกว้าง 390 และ 1280 px ยังไม่ได้ตรวจบน iPhone/Android จริง
