## บันทึกและรูปส่วนตัว

สมุดจดเก็บต้นฉบับแบบ Delta ที่ผ่านตัวกรอง ไม่ใช้ innerHTML ของผู้ใช้ โครงสร้างสี/ไฮไลต์และรูปถูกเก็บใน `ru_study_workspaces.payload` แยกตามเจ้าของ รูปเป็น ID อ้างถึง private storage ไม่เก็บ URL สาธารณะหรือ URL ที่หมดอายุลงเนื้อหา

ก่อนลงชื่อ: localStorage / IndexedDB ของ origin นี้ หลังลงชื่อ: cache แยก user ID และ RPC สำหรับ owner เท่านั้น หากเครื่องอื่นแก้ก่อนจะหยุดการซิงก์และให้เลือกฉบับ ไม่เขียนทับเงียบ ๆ

“ส่งออกโน้ตพร้อมรูป” รวม snapshot และ image data ลง JSON ในเครื่อง ไม่ส่งไปบริการอื่น การย้าย GitHub Pages → Vercel ต้องนำเข้าสำรองหรือเข้าสู่บัญชีเดียวกัน เพราะ localStorage/IndexedDB ไม่ข้าม origin

## 16 พ.ย. 2569 — พื้นที่กลางสำหรับทุกเครื่อง

ตามคำขอเจ้าของ แอปเปิดพื้นที่กลางเดียวทันทีโดยไม่ล็อกอิน ทุกคนที่เปิดเว็บอ่าน แก้ไข และลบข้อมูลในพื้นที่นี้ได้ ค่า `sharedKey` ใน `dist/shared-space.js` จึงเป็นค่าพื้นที่สาธารณะโดยตั้งใจ ไม่ใช่ service-role key และไม่มีการเปิดสิทธิ์อ่านพื้นที่ส่วนตัวอื่นหรือแก้ RLS ทั้งฐานข้อมูล

ใช้ Edge Function `personal-study` เดิมผ่าน workspace key คงที่ ทุก origin/browser/device จึงเปิด space ID เดียวกัน การซิงก์ยังตรวจ revision เพื่อไม่เขียนทับการแก้ไขพร้อมกัน และตรวจข้อมูลใหม่ทุก 5 วินาทีเมื่อหน้าเว็บเปิดอยู่

เมื่อเปิดรุ่นใหม่จากเบราว์เซอร์เดิม แอปอ่าน private key เดิมและ account link เดิมถ้ามี คัดลอกโน้ต/รูป/ความคืบหน้าเข้าพื้นที่กลางอัตโนมัติ ต้นฉบับไม่ถูกลบ คัดลอกโน้ตที่ค้างใน cache เป็นอีกฉบับเมื่อแตกต่างกัน เก็บ migration receipts ใน cloud payload เพื่อให้การเปิดจาก browser อื่นไม่คืนโน้ตที่ลบไปแล้ว รูปใช้ชื่อใหม่ตาม source workspace การอ่านหรืออัปโหลดไม่สำเร็จจะไม่บันทึก receipt จึงลองใหม่ได้ ไม่มีการแจก key ของพื้นที่เดิม

การย้ายไม่สามารถพบข้อมูลในเบราว์เซอร์ที่ไม่เคยเปิดรุ่นใหม่นี้ได้ ให้เปิดจากแต่ละเบราว์เซอร์เก่าที่มีงานหนึ่งครั้ง หากค่าความคืบหน้าชนกันจะคงค่าของพื้นที่กลางไว้ ต้นฉบับเดิมยังอยู่สำหรับกู้คืน
